# RU Providers для Nuvio

Локальные скраперы для [Nuvio](https://nuvio.wiki) с русской озвучкой. В репозитории только два источника:

| Скрапер | Сайт | Что ищет | Качество |
|---|---|---|---|
| **HDRezka** | rezka.ag | Фильмы и сериалы | до 1080p (mp4) |
| **YummyAnime** | old.yummyani.me | Аниме: сериалы и фильмы | до 720p (m3u8) |

## Установка

1. Откройте Nuvio → **Settings → Local Scrapers**.
2. Добавьте адрес репозитория (окончание `refs/heads/main/` обязательно):

   ```
   https://raw.githubusercontent.com/aglrm/nuvio-providers/refs/heads/main/
   ```

3. Включите **HDRezka** и **YummyAnime**.

## Как работают

### HDRezka
- Берёт русское и оригинальное название из TMDB, ищет на сайте и сверяет год выхода.
- Отдаёт озвучку, выбранную на сайте по умолчанию, плюс «Дубляж» и «Оригинал (+субтитры)», если они есть.
- Зашифрованные ссылки сайта (`#h…`) расшифровывает сам.
- Качество «1080p Ultra» не отдаёт: без премиум-аккаунта сайт вместо видео возвращает заглушку.
- Если rezka.ag не отвечает, пробует зеркала `hdrezka.ag` и `hdrezka.me`.

### YummyAnime
- Ищет аниме через API сайта (`/api/search`), а серии получает из `/api/anime/{id}/videos`.
- Видео берёт из плеера **Kodik** и показывает до 6 озвучек на серию. Первыми идут AniLibria, AniDUB, StudioBand, Dream Cast, AniStar, AnimeVost, JAM, SHIZA и Crunchyroll.
- Сезон из TMDB сопоставляет с записью на сайте по году выхода.
- В TMDB продолжения часто входят в тот же сезон, а на сайте это отдельные записи. Скрапер сам переносит номер серии в следующую часть. Пример: «Магическая битва», серия 27 → «Магическая битва 2», серия 3.
- Короткие спешлы при переносе пропускает.
- Плееры CVH, Alloha и Aksor пока не поддерживаются.

## Если стримов нет

- **HDRezka.** Откройте rezka.ag в браузере на том же устройстве. Если сайт переехал, поменяйте `DOMAINS` в начале `providers/hdrezka.js`.
- **YummyAnime.** Проверьте, открывается ли old.yummyani.me. Аниме, у которого на сайте нет серий в плеере Kodik, скрапер не найдёт.
- Ссылки на видео выдаются на ваш IP и действуют ограниченное время. Если стрим перестал запускаться, обновите список источников.

## Структура

```
manifest.json          — список скраперов для Nuvio
providers/hdrezka.js   — HDRezka
providers/yummyanime.js — YummyAnime
```

Скраперы написаны на Promise-цепочках без async/await, как того требует Nuvio. Новый скрапер нужно вручную добавить в `manifest.json`.

## Отказ от ответственности

Репозиторий не хранит видео. Весь контент находится на сторонних сайтах.
